# Manager Call

Desktop application for sales managers to manage client calls.

## Features
- Client management with Excel/CSV import
- Call queue per manager with auto-date scheduling
- Call scripts with quick replies (Ctrl+1-9)
- Calendar view with overdue highlighting
- Reports + CSV exports
- Auto-update from GitHub releases
